# PERO-99 profile setup

This package recreates the terminal-style structure of the reference profile: custom SVG header, self-hosted contribution heatmap, profile README and a GitHub Actions updater.

## Install

1. Replace the contents of `PERO-99/PERO-99` with these files.
2. Commit and push.
3. Open **Settings → Actions → General**.
4. Enable **Read and write permissions** for workflows.
5. Run **Update GitHub Profile** manually once.
6. The contribution SVG will then be refreshed daily.

The reference profile also contains a personal ASCII portrait. I have deliberately left that out of this first package because it requires your photo; adding a random/generated portrait would not actually make it your profile.
